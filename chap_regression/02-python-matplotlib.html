Daten visualisieren mit Matplotlib

Die Bibliothek matplotlib.pyplot (meistens als plt importiert) ist der Standard für wissenschaftliche Diagramme in Python. Ein typischer Plot besteht aus drei Schritten: Daten bereitstellen, Plot-Befehl ausführen, Anzeigen.

Liniendiagramme

In einem Liniendiagramm werden Punkte miteinander verbunden. Wir müssen dazu einfach eine Liste von x-Koordinaten (x) und eine Liste von y-Koordinaten (y) angeben. Die entsprechenden Punkte werden dann in dieser Reihenfolge miteinander verbunden. Geben wir keine Liste von x-Koordinaten an, so wird dafür einfach [0, 1, 2, …] verwendet.

Beispiel. Grundgerüst eines Linien-Plots

Streudiagramme (Scatter Plots)

Manchmal wollen wir Punkte nur als Einzelwerte darstellen, ohne sie mit einer Linie zu verbinden (z. B. wenn es keinen sinnvollen zeitlichen Zusammenhang gibt, wie es bei Messdaten oft der Fall ist). Dafür nutzen wir den Befehl plt.scatter. Dieser funktioniert genau analog zu plt.plot, nur werden da die Punkte nicht miteinander verbunden.
