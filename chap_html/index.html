HTML und CSS

Dieses Kapitel zeigt, wie eine Webseite aufgebaut ist und wie sie gestaltet wird. Sie brauchen dazu keinen Editor und kein Programm zu installieren: Jede Übung hat eine Werkbank mit Editor und Vorschau direkt in dieser Seite.

So arbeiten Sie mit dieser Seite

  • Schreiben Sie Ihren Code links in die Werkbank. Die Vorschau rechts aktualisiert sich automatisch, mit Ctrl/⌘ + Enter sofort.
  • Braucht eine Übung zwei Dateien, hat die Werkbank die Reiter index.html und style.css. Das <link>-Tag verbindet die beiden, genau wie auf einem echten Webserver.
  • Ihr Code bleibt in diesem Browser gespeichert, auch wenn Sie die Seite schliessen. Mit Herunterladen holen Sie eine Datei auf den Computer.
