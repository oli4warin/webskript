Diese Seite deckt nur den Python-Teil des Kapitels ab: den Abschnitt «Hypothesentests mit Python» samt den dazugehörigen Übungen 3.14–3.20. Die übrigen Abschnitte (Zufallsgrössen, berühmte Verteilungen, Tests von Hand mit Wahrscheinlichkeitstabelle oder Taschenrechner) enthalten keinen Code und bringen als Webseite keinen Mehrwert gegenüber dem gedruckten Skript.

So arbeiten Sie mit dieser Seite

  • Jede Übung hat eine Werkbank mit Python-Editor. Mit Ausführen oder Ctrl/⌘ + Enter läuft Ihr Code, die Ausgabe erscheint rechts.
  • Der Code läuft wirklich in Ihrem Browser (mit Pyodide, inklusive numpy, scipy und für Plots matplotlib) – dafür lädt die Werkbank beim ersten Ausführen auf einer Seite eine Python-Umgebung aus dem Internet nach. Das dauert je nach Verbindung bis zu einer Minute; danach ist es für den Rest des Seitenaufrufs schnell. Ohne Internetverbindung funktioniert das Ausführen nicht.
  • Ihr Code bleibt in diesem Browser gespeichert, auch wenn Sie die Seite schliessen. Mit Herunterladen holen Sie eine Datei auf den Computer.
