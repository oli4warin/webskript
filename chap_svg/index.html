SVG — Scalable Vector Graphics

Ein Bild, das nicht aus Pixeln besteht, sondern aus einer Bauanleitung: Zeichne einen Kreis hierhin, einen Strich dorthin. Sie schreiben diese Anleitung selber — und weil sie nur Text ist, brauchen Sie dafür nichts als diese Seite. Jede Übung hat eine Werkbank mit Editor und Vorschau.

So arbeiten Sie mit dieser Seite

  • Schreiben Sie Ihren Code links in die Werkbank. Die Vorschau rechts aktualisiert sich automatisch, mit Ctrl/⌘ + Enter sofort.
  • Der Reiter heisst bild.svg: Was Sie schreiben, ist eine vollständige Bilddatei. Mit Herunterladen holen Sie sie auf den Computer und können sie im Browser oder in einer Webseite verwenden.
  • Ihr Code bleibt in diesem Browser gespeichert, auch wenn Sie die Seite schliessen.
  • Die Animationen auf dieser Seite laufen wirklich — anders als im gedruckten Skript, wo nur ein starres Bild davon stehen kann.
