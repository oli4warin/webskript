Diskrete dynamische Systeme

Wie sich Populationen, Epidemien und andere Grössen von einem Zeitschritt zum nächsten entwickeln — als Python-Simulation statt als starre Formel. Jede Übung hat eine Werkbank, in der Sie Code direkt im Browser schreiben, ausführen und verändern können, inklusive der erzeugten Diagramme.

So arbeiten Sie mit dieser Seite

  • Jede Übung hat eine Werkbank mit Python-Editor. Mit Ausführen oder Ctrl/⌘ + Enter läuft Ihr Code, Konsolenausgabe und erzeugte matplotlib-Diagramme erscheinen darunter.
  • Der Code läuft wirklich in Ihrem Browser (mit Pyodide, inklusive numpy und matplotlib) — dafür lädt die Werkbank beim ersten Ausführen auf einer Seite eine Python-Umgebung aus dem Internet nach. Das dauert je nach Verbindung bis zu einer Minute; danach ist es für den Rest des Seitenaufrufs schnell. Ohne Internetverbindung funktioniert das Ausführen nicht.
  • Ihr Code bleibt in diesem Browser gespeichert, auch wenn Sie die Seite schliessen. Mit Herunterladen holen Sie eine Datei auf den Computer.
